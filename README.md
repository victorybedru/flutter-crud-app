# Flutter CRUD Application

A Flutter application demonstrating CRUD operations using JSONPlaceholder API with Provider state management.

## Features
- Create, Read, Update, Delete posts
- Provider state management
- HTTP network requests
- Loading and error states
- Form validation
- Material Design 3
